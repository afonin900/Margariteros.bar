# Реклама

Это часть аналитики: здесь готовятся требования к измерению Google Ads и Meta,
а не запускаются кампании.

Хранить здесь можно план конверсий, требования к Pixel/Dataset и CAPI,
правила UTM/click-id, чек-листы диагностики и документы для одобрения.

Нельзя менять бюджеты, кампании, аудитории, пиксели или подключать аккаунты
без явного одобрения владельца.

## Рабочий доступ к Google Ads и GA4

Для проверки рекламы бара используется общий Jungle MCP и его сервис AdLoop.
Он читает только те Google Ads-аккаунты и GA4-свойства, к которым уже имеет
доступ Google-пользователь владельца. Для Margariteros выделен отдельный
клиент Jungle с доступом только к AdLoop.

Обычный аудит включает кампании, объявления и их модерацию, реальные конечные
ссылки, шаблоны отслеживания, UTM, события GA4 и связку рекламы с аналитикой.
Изменения рекламы остаются отдельным согласованием.
