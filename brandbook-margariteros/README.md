# Margariteros — брендбук для агентов

Это переносимый пакет для любого GPT-проекта, чата или агента, который готовит визуал либо публичный текст для Margariteros.

## Что прикреплять

Для обычной задачи (пост, афиша, Stories, обработка реального фото) прикрепите:

1. `BRAND_GUIDE.md` — всегда;
2. `visuals/logo-primary-current.png` — всегда;
3. `visuals/style-reference-board.png` — если агент генерирует или собирает визуал.

`visuals/mascot-reference-optional.png` прикрепляйте **только**, когда в результате действительно нужен маскот. Для обычных постов он не нужен: главную роль играет настоящее фото или видео бара.

## Как использовать в Web ChatGPT

1. Создайте проект `Margariteros`.
2. Загрузите из списка выше нужные файлы.
3. Содержимое `BRAND_GUIDE.md` вставьте в инструкции проекта целиком.
4. В каждом задании передайте только подтверждённые факты: дату, время, формат вечера, цену, предложение и реальные фото. Нельзя додумывать ни один из них.

Файлы PNG оставлены отдельными, чтобы их можно было прикреплять к любому новому проекту без доступа к этому репозиторию.

## Состав

- `BRAND_GUIDE.md` — правила языка, палитры, шрифтов, композиции и стоп-правила;
- `visuals/logo-primary-current.png` — актуальный большой логотип PNG, 2250 × 2250;
- `visuals/style-reference-board.png` — утверждённое визуальное направление Lime Fiesta;
- `visuals/mascot-reference-optional.png` — эталон маскота, только для задач с персонажем.
