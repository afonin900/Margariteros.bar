# Remotion — вертикальный Reel

Прототипы: живое фото — главный кадр, буквы анимируются отдельно.
Цвета Lime Fiesta только на акцентах, не на лице.

- Лайм `#C6FF00` — полоска и дата
- Оранжевый `#FF5A2E` — время, дата переливается
- Имя диджея белое
- У START одна иконка ноты из пакета, больше декора нет

Не публикуется отсюда. Готовый MP4 копировать в `content/weeks/…/<канал>/`.

```bash
cd content/production/remotion
bun install
bun run render:dragon
```

Результат: `out/saturday-dragon.mp4` (1080×1920, 7 с).

## DJ Kike — фоновая анимация без zoom-in

Исходное фото движется по кадру слева направо и чуть вверх; его масштаб не
меняется по ходу ролика. Фиксированный crop убирает чёрные полосы исходника.
Оформление ограничено тонкой лаймовой рамкой и малым оранжевым акцентом даты:
без логотипа. Дата, DJ и подтверждённое время входят по очереди.

```bash
bun run render:kike
```

Результат: `out/friday-kike.mp4` (1080×1920, 7 с). Это черновик, не публикация.
