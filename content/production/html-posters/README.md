# HTML-афиши 9:16

Генератор пятничных обложек в том виде, как бар уже публикует Reel:
живое фото на весь кадр и короткий белый текст поверх.

Цепочка:

```text
подтверждённый JSON → HTML-шаблон friday-reel → Playwright → PNG 1080×1920
```

Модель не рисует картинку. Она только заполняет поля. Публикация отсюда
не запускается.

## Быстрый старт

Из этой папки:

```bash
bun run render --data data/friday-kike-w33.json
```

Рендер идёт через установленный Chrome или Brave. Отдельный Playwright
нужен только если системного браузера нет.

Результат: `out/friday-kike-w33.png`.

## Поля JSON

| Поле | Обязательно | Пример |
| --- | --- | --- |
| `template` | нет, по умолчанию `friday-reel` | `friday-reel` |
| `photo` | да | относительный путь к реальному кадру |
| `photo_position` | нет | точка кропа, например `82% 88%` |
| `artist` | да | `DJ KIKE` |
| `dates` | нет | `14.08 \| 15.08` |
| `start` | нет | `21:00` или `START 21:00` |
| `location` | нет | `MARGARITEROS.BAR` |
| `source` | для фактчека | откуда взяты факты |

Пустое поле не рисуется. Значения `MISSING`, `DD.MM`, `GG:MM` рендер
останавливают.

Не выдумывать DJ, дату, время, цену или акцию. Сначала brief, потом JSON.

## Первый образец

`data/friday-kike-w33.json` повторяет официальный Reel: DJ KIKE,
14.08 | 15.08, START 21:00. Это фикстура пайплайна, не новый анонс.

## Куда дальше

Готовый PNG можно положить в пакет публикации и отдать в Postiz
**только как draft** после отдельного одобрения. Как подключается Postiz:
`../postiz/README.md`.
