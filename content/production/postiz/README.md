# Postiz в этом репозитории

Postiz — календарь публикаций бара. Афишу собираем здесь, в Postiz
отдаём только готовый файл и только после одобрения.

Свой Postiz уже отвечает по API. Чтобы инструменты MCP появились
в чате Grok, сессию нужно открыть с переменной `POSTIZ_API_KEY`.

## Что умеет MCP

После подключения агент видит инструменты:

| Инструмент | Зачем |
| --- | --- |
| `integrationList` | какие каналы подключены (Instagram, TikTok, …) |
| `postsListTool` | что уже стоит в календаре |
| `schedulePostTool` | создать **draft** / слот / публикацию |
| `integrationSchema` | правила площадки до отправки |

Публиковать (`type: now` или `schedule`) без отдельной фразы владельца
нельзя. По умолчанию только `draft`.

## Как подключить

Бар использует свой Postiz: `https://postiz.margariteros.bar`.

1. Ключ лежит в корневом `.env` как `POSTIZ_API_KEY`. Файл в git не попадает.
2. Проверка:

```bash
bun run content/production/postiz/check.ts
```

3. Чтобы Grok увидел MCP в новой сессии:

```bash
set -a && source .env && set +a
```

Конфиг проекта подставляет ключ в URL и сам ключ не хранит:

`.grok/config.toml` → `https://postiz.margariteros.bar/api/mcp/${POSTIZ_API_KEY}`

После этого в новой сессии: «покажи подключенные каналы Postiz».
Если отвечает списком аккаунтов — связь есть.

## Куда класть ключ

| Можно | Нельзя |
| --- | --- |
| корневой `.env` | коммит, чат, Issue, скриншот |
| переменная оболочки | `.grok/config.toml` с живым ключом |
| менеджер паролей | чужой репозиторий |

Если файл с ключом уже скачан — положи его как `.env` в корень
`Margariteros.bar` и напиши «файл на месте». Я проверю вход и не буду
печатать секрет.
