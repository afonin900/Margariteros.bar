# Export Presets

## Instagram feed / poster
- Canvas: 1080×1350 px
- Color: sRGB
- Format: PNG for graphics; high-quality JPEG only for photo-heavy final exports

## Story / Reel
- Canvas: 1080×1920 px
- Frame rate: 25 or 30 fps
- Video: H.264 MP4, sRGB/Rec.709
- Keep critical text inside supplied safe zones

## Horizontal video
- Canvas: 1920×1080 px
- Frame rate: 25 or 30 fps
- Video: H.264 MP4, Rec.709

## Print A4 / A6
- Resolution: 300 DPI
- Work in the final physical size
- Add 3 mm bleed in the layout application when required by the printer
- Convert to CMYK using the printer's requested profile only at final prepress
- Export final print PDF from a layout application; do not simply rename PNG files

## PNG asset export
- Isolated objects: RGBA, transparent background
- Finished templates/backgrounds: RGB or RGBA as appropriate
- Do not upscale assets during export
