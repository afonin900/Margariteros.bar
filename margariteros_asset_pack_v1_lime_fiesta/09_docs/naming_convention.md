# Naming Convention

Pattern: `lf_<category>_<subject>_<variant>_<dimensions>.<ext>`

Examples:

- `lf_mascot_wave.png`
- `lf_pattern_icons_repeat_tile.png`
- `lf_story_event_1080x1920_overlay.png`

Prefixes:

- `lf_` — Lime Fiesta
- `logo` — logo variants
- `mascot` — character poses
- `icon` — isolated icons
- `bg` — opaque backgrounds
- `overlay` — transparent overlays
- `pattern` — repeat tiles or borders
- `poster`, `story`, `video`, `highlight` — templates

Suffixes:

- `_blank` — complete background/template without event copy
- `_overlay` — transparent frame for placement over photo/video
- `_tile` — repeatable master module
- `_preview`, `_sheet`, `_guide` — documentation only, not production artwork
