# MARGARITEROS — Stage 8: Video / Social Templates Pack

## Состав

### Вертикальные карточки 1080×1920

- `lf_reel_intro_1080x1920_blank.png` / `overlay.png` — вступительный кадр Reels;
- `lf_story_event_1080x1920_blank.png` / `overlay.png` — анонс мероприятия;
- `lf_story_offer_1080x1920_blank.png` / `overlay.png` — акция или специальное предложение;
- `lf_reel_cta_1080x1920_blank.png` / `overlay.png` — финальный CTA-кадр.

`blank` содержит фирменный фон. `overlay` имеет прозрачный фон и предназначен для наложения поверх фото или видео.

### Горизонтальное видео 1920×1080

- `lf_video_title_1920x1080_blank.png` / `overlay.png` — титульный кадр;
- `lf_video_lower_third_1920x1080_overlay.png` — прозрачная нижняя треть;
- `lf_video_end_screen_1920x1080_blank.png` / `overlay.png` — финальный экран.

### Highlight covers 1080×1080

MENU, COCKTAILS, FOOD, EVENTS, MUSIC, OFFERS, LOCATION, CONTACT.

### Контрольные материалы

- `lf_social_pack_preview.png` — обзор пакета;
- `lf_reel_15s_storyboard.png` — последовательность 15-секундного ролика;
- `lf_reel_safe_zones_1080x1920.png` — безопасные зоны Reels/Stories;
- `lf_video_safe_zones_1920x1080.png` — безопасные зоны 16:9;
- `motion_guide.md` — рекомендации по анимации и экспорту.

## Производственный принцип

- исходные PNG-ассеты не увеличивались;
- фоновые текстуры повторяются плиткой вместо растягивания;
- логотип, маскот, иконки и декор только уменьшены методом Lanczos;
- маскот во всех анимациях сохраняет одну ножку бокала и одинаковое сомбреро;
- SVG-автовекторизация не применяется.
