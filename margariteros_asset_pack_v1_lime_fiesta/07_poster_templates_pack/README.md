## How to use

- Use a `*_blank.png` file as a ready-made background and place text/photos above it.
- Use a matching `*_overlay.png` file over a photograph or video frame.
- Do not stretch the A4/A6 templates. Send them to print at 100% scale.
- The empty brush strokes and panels are intentional text zones.
- `lf_template_zones_guide.png` explains the recommended content placement.
- `lf_template_usage_preview.png` is a presentation preview and is not a production source.

## Quality policy

- backgrounds are tiled from native seamless 1536×1536 masters;
- mascot and icon assets are reduced, never enlarged;
- wide decorative elements are repeated or centered rather than stretched;
- blank backgrounds are palette-optimized for reasonable file size without changing the limited brand palette;
- overlays remain transparent RGBA PNG files.
