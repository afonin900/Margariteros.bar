# Stage 5 — Pattern Pack

The pack is assembled from the approved high-resolution mascot, icon, and rebuilt decor masters. No source was extracted from a low-resolution brandbook page, and no production asset was enlarged.

## Production assets

- `lf_pattern_mascot_repeat_tile.png` — seamless transparent mascot tile;
- `lf_pattern_icons_repeat_tile.png` — seamless transparent icon tile;
- `lf_pattern_fiesta_repeat_tile.png` — denser seamless transparent fiesta tile;
- `lf_pattern_border_top.png` — native papel-picado top border;
- `lf_pattern_border_bottom.png` — native lime/chili divider;
- `lf_pattern_border_side.png` — vertical side-border module;
- three ready-made 2048×2048 pattern fields for quick use;
- `lf_pattern_sheet.png` — visual index.

## Usage

Repeat the `_tile.png` files without spacing. Scale tiles down freely. To cover a larger canvas, repeat more instances rather than enlarging a tile beyond 100%.
