# Правила общего входа Margariteros

Эта папка собирает семь независимых частей проекта в одном месте. Сначала
выбери нужную дочернюю папку и прочитай её `AGENTS.md`, `README.md` и другие
указанные там правила. Общие правила GitHub находятся выше, в
`/Users/afonin900/Github/AGENTS.md`.

- Не создавай общий Git-репозиторий и не делай общую сборку или общий выпуск.
- У каждой дочерней папки остаются свой `.git`, история и самостоятельный
  выпуск.
- Новые рабочие пути этого проекта — `/Users/afonin900/Github/Margariteros/*`.
- Не удаляй и не архивируй исторические файлы, секреты или старые материалы.
- Не меняй соседний репозиторий из другой дочерней папки без отдельной задачи.

Раскладка завершена 5 сентября 2026 года. Старые пути сохранены как ссылки
для совместимости; данные находятся в дочерних папках здесь.
