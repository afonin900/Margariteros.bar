## Как восстановить общий вход

Файлы в `templates/` — точные копии пяти документов общей папки на момент
фиксации. Их относительные ссылки рассчитаны на размещение рядом с семью
репозиториями, а не внутри `templates/` на GitHub.

На другой машине разместить семь самостоятельных репозиториев под одной
родительской папкой с исходными именами. После проверки существующих файлов
скопировать туда пять файлов из `templates/`, сохранив имена. Если документы
уже существуют, сначала сравнить их; не перезаписывать новую работу старой
копией. Файл рабочего пространства использует относительные пути; абсолютный
путь в поясняющих документах относится к текущей машине владельца.

Сохранённые здесь документы не заменяют резервную копию: в Git не включены
местные секреты, зависимости, кеши, текущие черновики других задач или Git
данных соседних репозиториев. Полная защищённая копия описана в отчёте.
Перемещение и создание старых совместимых ссылок уже выполнены локально;
обычный checkout этого репозитория не запускает перенос или публикацию.

После будущих изменений общей карты её копии здесь обновляются отдельно,
чтобы локальные документы и сохранённый снимок не расходились незаметно.
