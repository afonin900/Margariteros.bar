## Ограничения рекламы алкоголя

- Нельзя обходить модерацию заменой слов, синонимами или маскировкой смысла.
- Лицензия бара на продажу алкоголя сама по себе не отменяет правила Google Ads.
- Для польского рынка реклама алкоголя сильно ограничена; маршрут с коктейлями, текилой, мескалем и маргаритами нельзя использовать как безопасный рекламный лендинг.
- Ссылка `/section:menu/tacos` сейчас не подходит для рекламы: в ее содержимом есть алкогольное позиционирование и слова о коктейлях.

## Правильный рекламный маршрут

Сделать отдельную главную/посадочную страницу ChoiceQR с нейтральным позиционированием:

- мексиканская кухня;
- тако;
- события, музыка, атмосфера;
- бронирование;
- меню еды.

На этой странице не использовать алкогольные тексты, ассортимент и визуалы. Рабочее позиционирование: `Margariteros | Kuchnia meksykanska i wydarzenia w Warszawie`.

Не менять фактическое имя Google Business Profile только ради рекламы: оно должно соответствовать реальному бизнесу и вывеске.

## ChoiceQR и согласие на cookies

- У ChoiceQR нет подтвержденной настройки Google Consent Mode; не искать в его админке несуществующую галочку.
- `cookieSettings` ChoiceQR хранит выбор пользователя, но сам по себе не доказывает интеграцию с Consent Mode.
- По публичной конфигурации сайта `googleConsentModeAdvanced` выключен.
- Consent Mode можно настроить на стороне GTM, но до публикации нужен механизм, который передаст в GTM выбор посетителя. Иначе установка `denied` по умолчанию заблокирует аналитику навсегда.
- Поэтому пока не публиковать Consent Mode и не публиковать черновик GTM без согласованного механизма баннера.

## Цепочка сквозной аналитики

1. Реклама ведет на безопасную food/events/booking-страницу с UTM.
2. При бронировании сохраняются `gclid`, UTM, GA client ID и ID бронирования ChoiceQR.
3. При подтверждении бронирования можно отправлять лид.
4. При фактическом закрытии столика в Serve отправлять итоговую конверсию в GA4 Measurement Protocol и/или Google Ads offline conversion.
5. Дедупликация по ID бронирования обязательна.

Для этого нужна подтвержденная схема ChoiceQR Open API и интеграция ChoiceQR -> Serve. Публично подтверждено, что у ChoiceQR есть Open API, но конкретные методы и ключи еще не зафиксированы.

## Следующий шаг в новом диалоге

Сначала получить и зафиксировать способ передачи статуса cookie-согласия в GTM без выдуманных функций ChoiceQR. Затем подготовить к публикации веб-контейнер GTM и только после этого подключать серверный GTM и цепочку ChoiceQR -> Serve.
