# ADR-002 — Согласие остаётся first-party, пока ChoiceQR не докажет совместимость

## Контекст

Сайт должен одинаково честно обрабатывать выбор гостя о необязательной аналитике и рекламе. Своя cookie может быть доступна поддоменам `margariteros.bar`, но не может технически выставить cookie на внешнем домене ChoiceQR. Нет подтверждённого контракта, что ChoiceQR читает наш формат согласия.

## Решение

Храним версионированное согласие first-party в `margariteros_consent_v1` для `.margariteros.bar` со статусами `essential`, `analytics`, `marketing`, `updatedAt` и `policyVersion`. Мост `ChoiceConsentBridge` возвращает `unsupported`, пока не появятся документированный ChoiceQR API или script contract, живой readback Accept/Reject и отдельная юридико-техническая проверка.

## Почему

Нельзя выдавать наличие собственной cookie за применение выбора в чужой системе. Явная неподдержанность сохраняет честность перед гостем и не создаёт дорого исправляемую зависимость от недоказанного поведения поставщика.

## Последствия

Отказ не ограничивает контент, меню или бронь. Ни сайт, ни server-side транспорт не меняют `denied` на `granted` и не обходят выбор гостя. Поддержка ChoiceQR добавляется отдельным адаптером только после доказательства контракта.
