# Canva import and acceptance checklist

## Import

1. Canva → **Create a design** → **Import file**.
2. Import the required PPTX from `templates/`.
3. Replace all imported fonts with the built-in Canva families:
   - `Barlow Condensed` → Black Italic;
   - `Montserrat` → Bold / ExtraBold / Black.
4. Replace each grey photo rectangle with a real Canva **Frame**.
5. Keep logo, marker caps, papel picado, mascot and textures proportional.
6. Save the accepted master as a Canva Brand Template.

## Polish proof

Reject the import if any glyph is substituted, clipped or changes weight.

## Visual acceptance

- [ ] Headline reads at 270 px preview width.
- [ ] Headline uses no more than 3 lines and about 24 characters per line.
- [ ] Date and time remain together.
- [ ] Orange text is never placed on lime.
- [ ] Photo is still the dominant layer and text does not cover faces.
- [ ] Story/Reel critical content stays 250 px from top, 320 px from bottom and 90 px from sides.
- [ ] Reel cover still works inside the central 1080×1350 feed crop.
- [ ] No `MISSING`, `DD.MM`, `GG:MM` or instructional copy remains.
- [ ] Source facts and owner approval are recorded.

## Export

- Feed/carousel: PNG 1080×1350.
- Story: PNG or MP4 1080×1920.
- Reel cover: PNG 1080×1920; verify both full-screen and feed crop.
- Print is outside this checklist and requires a separate 300 DPI source.
