# Margariteros Lime Fiesta — Canva Production Pack

A compact production system for posters, carousels, Stories and Reel covers. Public-facing copy is written in natural modern Polish; unknown event facts are never invented.

## Start here

1. Read the root [`DESIGN.md`](../DESIGN.md).
2. Open [`dashboard/index.html`](dashboard/index.html) for previews and downloads.
3. Import one PPTX from [`templates/`](templates/) into Canva.
4. Follow [`reference/canva-import-checklist.md`](reference/canva-import-checklist.md).
5. Replace placeholders with confirmed facts and real bar photography.
6. Obtain owner approval before publication.

## Canonical typography

- **Barlow Condensed Black Italic** — short event headlines.
- **Montserrat 700–900** — dates, time, address, CTA and supporting facts.
- Polish acceptance string: `ĄĆĘŁŃÓŚŹŻ ąćęłńóśźż`.

Bangers, Archivo Black, Arial Black and Nunito are legacy-only and must not appear in new production materials.

## Canva transport files

- `templates/margariteros-afisza-4x5.pptx`
- `templates/margariteros-karuzela-5-slajdow.pptx`
- `templates/margariteros-story-9x16.pptx`

PPTX is a transport format. After import, replace grey rectangles with Canva Frames and save the accepted result as a Brand Template.

## Safety

Do not publish materials containing `MISSING`, `DD.MM`, `GG:MM` or instructional labels. Do not stretch raster assets. Mascot anatomy remains one glass stem and base, without human legs.
