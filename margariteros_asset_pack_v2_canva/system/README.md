# Margariteros Canva System

Система для ручной сборки афиш, каруселей и Stories в Canva без AI.

## Типографика

- Заголовок: `Barlow Condensed Black Italic`.
- Факты и подписи: `Montserrat` в весах 700–900.
- Оба шрифта проверены на полный польский набор:
  `ĄĆĘŁŃÓŚŹŻ ąćęłńóśźż`.
- В Canva оба семейства доступны из стандартного списка шрифтов. Не использовать
  Bangers в новых редактируемых шаблонах: его импорт уже дал некорректную
  подмену польских символов.

## Маркерная подложка

Каждый цвет собран из трёх PNG:

1. `marker-left.png` — неизменяемый левый край.
2. `marker-center-stretch.png` — единственная часть, которой меняют ширину.
3. `marker-right.png` — неизменяемый правый край.

В Canva выровнять три части по вертикальному центру и сгруппировать. При
изменении текста разгруппировать, растянуть только середину, передвинуть правый
край и снова сгруппировать. Края никогда не масштабировать.

`marker-crop-master.png` — быстрый вариант: его не растягивают, а только
обрезают по ширине инструментом Crop. Так фактура кисти не деформируется.

## Стикеры

Папка `stickers` содержит только рабочий минимум:

- чистый логотип;
- papel picado;
- срез лайма;
- календарь, локация, бронь и DJ.

Стикеры не должны конкурировать с фотографией. В обычной афише допустим один
крупный акцент или до двух маленьких служебных значков. Маскот сюда намеренно
не включён: он используется только в специальных публикациях.

## Порядок сборки Canva

1. Реальная фотография на весь холст.
2. Затемнение или цветовая коррекция.
3. Маркерная подложка, если она нужна композиции.
4. Редактируемый заголовок Barlow Condensed Black Italic.
5. Факты Montserrat Bold/ExtraBold.
6. Один фирменный стикер.

Не растягивать логотип, papel picado и срез лайма сверх исходного размера.
