# Шрифты

- `BarlowCondensed-BlackItalic.ttf` — событийные заголовки.
- `Montserrat-Variable.ttf` — даты, время, адрес, CTA и короткие подписи.

Оба файла взяты из официального репозитория Google Fonts и распространяются
по SIL Open Font License. Проверка shaping прошла для полного польского набора:

`ĄĆĘŁŃÓŚŹŻ ąćęłńóśźż`

В Canva предпочтительно выбирать встроенные семейства `Barlow Condensed` и
`Montserrat`. Локальные файлы нужны для Open Design, Remotion и резервного
импорта без подмены.
