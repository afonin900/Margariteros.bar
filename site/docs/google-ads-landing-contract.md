# Рекламная главная Margariteros

## Рабочие адреса

- Польский: `/pl/`
- Английский: `/en/`
- Испанский: `/es/`

Русский `/ru/` остаётся обычной гостевой страницей и не входит в первый рекламный запуск.

## Что меняется динамически

- язык баннера, кнопок, событий и пустых состояний определяется адресом страницы;
- опубликованные события загружаются из коллекции `events` в Emdash;
- в меню и бронь переносятся только разрешённые `utm_source`, `utm_medium`, `utm_campaign`, `utm_term`, `utm_content`, `gclid`, `gbraid`, `wbraid`;
- имя, телефон, e-mail, комментарий и другие личные данные не переносятся.

Для оценки списка без публикации вымышленных событий используется отдельный режим `?preview=events`. Он показывает две автоматически датированные карточки с постоянной пометкой TEST/PRUEBA, без брони и без отдельной страницы события. Обычная страница эти примеры никогда не показывает.

## Куда ведут кнопки

- меню: `https://qr.margariteros.bar/section:menu`;
- бронь: `https://qr.margariteros.bar/booking`.

Встраивание формы через ChoiceQR API не включено: подтверждённого договора и безопасного чтения API пока нет. До этого используется обычный переход в живую форму ChoiceQR.

## Согласие и GTM

- до загрузки GTM страница отправляет стандартную команду Google Consent Mode v2 с `denied` для `analytics_storage`, `ad_storage`, `ad_user_data`, `ad_personalization`;
- GTM загружается и при отказе, чтобы поддержать Advanced Consent Mode и обезличенные сигналы;
- после выбора отправляется стандартная команда `update`;
- решение дублируется в текущую общую куку ChoiceQR `cookieSettings` на домене `.margariteros.bar`: `required` для отказа и `required-ga-gtag-fb` для полного согласия;
- частичное согласие намеренно приравнивается к отказу для ChoiceQR, потому что текущая платформа объединяет Google Analytics и рекламные сигналы.

Формат `cookieSettings` подтверждён чтением живого ChoiceQR, но не опубликован поставщиком как стабильный договор. После каждого заметного обновления ChoiceQR нужен повторный чистый переход и чтение результата.

## Граница рекламы

В видимом тексте, метаданных, навигации и выбранных фотографиях рекламной главной нет алкогольного позиционирования. Запуск рекламы и публикация сайта требуют отдельного разрешения владельца.
