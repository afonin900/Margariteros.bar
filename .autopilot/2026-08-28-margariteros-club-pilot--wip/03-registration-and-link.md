# 03 — Регистрация партнёра и постоянная ссылка

**Требования:** R07, R08, R13, R16, R20, R21, R24, R35i
**Blocked by:** 02
**Зона:** `site/src/pages/api/club/` · `site/src/pages/r/` · `site/src/pages/[locale]/club/`
**Волна:** 3
**Status:** ready

## Что должно заработать

Кандидат проходит минимальную регистрацию, сразу получает постоянную ссылку, а по ссылке виден честный статус. Активный тестовый партнёр получает инструкции/QR для ANDREI10; pending-ссылка не обещает скидку. Telegram contract готов для native contact и не принимает чужой номер как подтверждённый.

## Из брифа, дословно

> «Телефон подтверждается ... запрос в Телеграм-боте номера телефона»
> «кнопку стать партнером ... регистрируешься и получаешь свою партнерскую ссылку»
> «человек, приходя по ссылке партнера, просто получает скидку»

## Разделы спецификации

Telegram и web; RefRef; Первый запуск и пустые состояния; Неверный ввод, сбои и прерывания.

## Критерии приёмки

- [ ] Регистрация возвращает тот же provisional URL при безопасном повторе
- [ ] `/r/<opaque-code>` различает pending, active, suspended и unknown
- [ ] Active POC URL однозначно ведёт к ANDREI10 coupon/QR инструкции
- [ ] Telegram contact contract отвергает contact другого пользователя
- [ ] UI не раскрывает телефон, внутренние Syrve IDs и баланс постороннему
- [ ] SSR/API тесты проходят без JavaScript и без live credentials
