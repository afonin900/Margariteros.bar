# Как читать эту папку

- `dashboard.html` — открывается сам в начале сборки; можно и двойным кликом. Этапы, прогресс, время, что осталось. Обновляется сам, пока сборка идёт. `index.html` рядом — тот же файл под другим именем.
- `<дата>-<проект>/` — папка одной сборки. Суффикс `--wip` значит «ещё делается»; после сдачи он снимается. Внутри:
  - `<дата>-brief.md` — исходная задача владельца и последующие дополнения;
  - `manifest.md` — список требований и судьба каждого;
  - `spec.md` — спецификация;
  - `tickets/` — таски сборки.

Если сборка прервалась — скажи агенту «продолжи автопилот», он поднимет состояние отсюда.
