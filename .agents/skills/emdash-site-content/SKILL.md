# Emdash website content

Use Emdash only for the Margariteros website collections `homepage` and `events`.

1. Read `references/content-contract.md` before any write.
2. Read the current entry before changing it.
3. Keep the administration labels in English and content values separate for `pl`, `en`, `ru`, and `es`.
4. Never invent event facts, dates, prices, performers, or offers. Require a fact source.
5. Use draft status until every language listed in `published_locales` is complete.
6. Preview and read back the exact entry after a write.
7. Deletion and publication require the owner's explicit permission.

Do not create social channels, publication schedules, Buffer/Postiz records, or creative-asset workflows in Emdash.
