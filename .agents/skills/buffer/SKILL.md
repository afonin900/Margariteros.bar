# Buffer для Margariteros

Используйте `buffer` только для задач Margariteros. Ключ передаётся защищённым
хранилищем в `BUFFER_API_KEY`; не записывайте его в Git, `.buffer/config.json`,
аргументы или чат.

1. Сначала проверьте среду: `buffer doctor --verbose`.
2. Для чтения используйте `buffer account`, `buffer channels list` и
   `buffer posts list --channel-id <id>`.
3. До создания черновика или публикации покажите текст, канал и время.
4. Любая команда изменения требует явного «можно». Перед ней выполните ту же
   команду с `--dry-run`; публикацию без отдельного разрешения не делайте.
5. Для точной формы команды используйте `buffer schema describe <группа> <команда>`.

`.buffer/config.json` хранит только несекретные настройки проекта.
